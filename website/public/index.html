Translate Python and Pybricks into Blockly blocks.

BTP Translator is a Windows desktop app for students and everyday users. Paste a Python program, press Translate, and inspect the blocks. It runs on your computer after installation.

What it does

  • Opens with the HAMDAN SYSTEMS screen, then ownership and contact details.
  • Edits Python with colour syntax highlighting.
  • Translates variables, conditions, loops, functions, comments, and supported Pybricks robot code.
  • Keeps unsupported lines visible and explains them. It does not claim a full translation when code was left out.
  • Works offline after installation. No Python or Node.js setup is required.

Windows requirements

    Install

    1. Download BTP-Translator-Setup.exe.
    2. Open the installer and choose a folder if you want one other than the suggested location.
    3. Finish the wizard. It adds a Start menu shortcut and can add a desktop shortcut.
    4. Open BTP Translator, wait for the two startup screens, and press Spacebar.
    5. Choose an example or open a .py file, then press Translate.
